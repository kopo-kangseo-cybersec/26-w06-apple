# 🍎 사과 숫자 게임

## 게임 소개

사과 타일을 드래그해 직사각형 영역을 만들고, 영역 안 숫자의 합을 10의 배수로 맞추는 1분 게임입니다. 성공하면 선택한 사과가 수확되고 숫자의 합만큼 점수를 얻습니다. 사과가 떨어져 아래쪽 빈자리를 채우며, 새 사과가 위쪽에 나타납니다.

## 게임 방법

1. **게임 시작**을 눌러 60초 도전을 시작합니다.
2. 마우스나 손가락으로 사과를 누른 채 드래그해 직사각형의 반대쪽 모서리까지 이동합니다. 영역 안의 사과가 모두 선택됩니다.
3. 선택 영역의 합계가 10, 20, 30 등 10의 배수이면 사과가 수확됩니다. 맞지 않으면 사과는 그대로 남습니다.
4. 20×20 보드에서 가능한 한 높은 점수를 얻으세요. 작은 화면에서는 보드를 좌우로 이동할 수 있습니다.

현재 점수와 남은 시간이 표시되며, 최고 점수는 이 페이지가 열려 있는 동안의 최고 기록입니다. 최고 점수는 게임이 끝났을 때 갱신되고, 신기록을 세우면 사과가 떨어지는 축하 모션이 재생됩니다. 진행 중 다시 시작하면 해당 게임의 점수는 기록되지 않으며, 페이지를 새로고침하거나 닫으면 최고 점수가 초기화됩니다.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript를 사용하고 화면, 스타일, 게임 동작을 각각 `index.html`, `style.css`, `script.js`로 분리했습니다. Pointer Events로 마우스와 터치 입력을 처리하며, 점수와 최고 점수는 페이지가 열려 있는 동안 JavaScript 메모리에 유지합니다.

## 실행 방법

저장소를 내려받아 `index.html`을 브라우저에서 여세요. 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

- 20×20 숫자 보드와 직사각형 드래그 선택
- 합이 10의 배수일 때 사과를 수확하고 합계만큼 점수 획득
- 수확 뒤 열 단위로 사과가 아래로 떨어지고 위쪽은 새 사과로 채워지는 효과
- 60초 타이머, 현재 점수, 페이지 방문 중 최고 점수 표시
- 신기록 달성 시 사과가 떨어지는 축하 모션
- 모바일에서 사용할 수 있는 터치 입력과 보드 좌우 이동
