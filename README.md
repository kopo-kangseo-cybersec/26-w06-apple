# 🍎 사과 합 10 게임

## 게임 소개

사과에 적힌 숫자를 드래그로 이어 합이 10이 되도록 수확하는 퍼즐 게임입니다. 1분 동안 가능한 한 많은 사과를 수확하고 최고 점수에 도전해 보세요.

### 게임 규칙

- **게임 시작** 버튼을 누르면 8×8 보드와 1분 카운트다운이 시작됩니다.
- 상하좌우로 인접한 숫자만 이어서 선택할 수 있습니다.
- 선택한 숫자의 합이 10이 되면 드래그를 놓아 수확합니다. 수확한 사과 한 개당 1점입니다.
- 합이 10을 넘으면 현재 드래그 선택이 취소됩니다.
- 수확한 사과가 있던 열에서는 위쪽 사과들이 아래로 내려오고, 맨 위는 새로운 숫자로 채워집니다.
- 최고 점수는 브라우저에 저장되며, 기록을 갱신하면 꽃잎 컨페티가 나타납니다.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript를 각각 별도 파일로 작성했습니다. 사과 그림은 CSS와 인라인 SVG로 표현해 별도의 이미지 파일이나 라이브러리를 사용하지 않습니다. Pointer Events로 마우스와 터치 드래그를 처리하고, 브라우저 `localStorage`에 최고 점수를 보관합니다. 사용자의 모션 감소 설정도 존중합니다.

### 파일 구성

- `index.html` — 게임 화면과 점수·타이머·보드의 HTML 구조
- `style.css` — 반응형 레이아웃, 사과 모양, 선택 강조와 애니메이션
- `script.js` — 숫자 생성, 드래그 경로와 합계 판정, 점수·타이머, 열별 낙하와 최고 점수 효과

## 실행 방법

세 파일을 같은 폴더에 둔 뒤 `index.html`을 브라우저에서 여세요. 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다. 페이지가 열리면 **게임 시작** 버튼을 눌러 플레이합니다.

## 커스터마이징한 부분

8×8 보드, 1분 제한 시간, 합계 10 규칙을 적용했습니다. 사과 모양 위에 숫자를 표시하고 드래그 중인 경로를 하이라이트합니다. 수확한 열만 아래로 정리하고 새 숫자로 채워 보드에 빈칸이 남지 않도록 했으며, 최고 기록을 세우면 꽃잎이 흩날리는 축하 효과를 보여줍니다.

자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.
