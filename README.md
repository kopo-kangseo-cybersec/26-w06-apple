# 🍎 사과 합 10

## 게임 소개

8×8 격자에서 상하좌우로 이어진 숫자 사과를 드래그해 합이 10이 되면 수확하는 게임입니다. 제한 시간 1분 동안 더 많은 사과를 수확하고 최고 점수에 도전해 보세요. 수확한 사과마다 1점이며, 최고 점수는 브라우저에 저장됩니다.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript를 `index.html`, `style.css`, `script.js` 파일로 나누어 구현했습니다. 시작 버튼을 누르면 게임과 타이머가 시작됩니다. 드래그 경로의 인접 여부와 숫자 합계를 판정하고, 수확한 열의 사과는 아래로 내려오며 맨 위는 새 사과로 채웁니다. 최고 점수 갱신 시 꽃잎 컨페티 효과를 보여줍니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. **게임 시작**을 누르면 1분 타이머가 시작됩니다.

## 커스터마이징한 부분

사과 모양 아이콘 안에 숫자를 표시합니다. 시작 버튼을 눌러야 게임과 타이머가 시작되며, 숫자 칸을 상하좌우로 이어서 선택하도록 했습니다. 드래그 중인 칸을 하이라이트하고 합이 10을 넘으면 현재 드래그를 즉시 무효로 처리합니다. 수확 후에는 위쪽 사과가 애니메이션과 함께 아래로 내려오고 맨 위 빈칸은 새 사과로 채웁니다. 선택을 성공하면 사용한 칸 수만큼 점수를 얻으며, 최고 점수 갱신 시 꽃잎 컨페티가 날립니다. 최고 점수는 다음 방문에도 유지됩니다.

자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.
