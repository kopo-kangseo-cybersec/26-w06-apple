# 🍎 사과게임

## 게임 소개

6×6 게임판에서 인접한 사과를 드래그로 이어 합계 10을 만들면 점수를 얻는 게임입니다. 선택 중인 사과와 합계가 실시간으로 표시되며, 합계가 10을 넘으면 선택이 자동으로 취소됩니다. 제한 시간은 2분이고, 현재 점수와 최고 점수를 확인할 수 있습니다.

## 어떻게 만들었나요

실습 가이드의 단계에 따라 게임을 한 번에 구현한 다음, 드래그 중 선택 표시와 합계 초과 시 취소 동작을 추가하고 화면과 격자 크기를 커스터마이징했습니다. HTML, CSS, Vanilla JavaScript만 사용했으며 게임 전체를 하나의 `index.html` 파일에 담았습니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

- 기본 8×8 격자를 6×6으로 변경했습니다.
- 숫자 대신 사과 이모지(🍎)로 칸을 표시합니다.
- 드래그 중 선택된 칸을 강조하고 합계를 실시간으로 보여줍니다.
- 합계가 10을 넘으면 현재 선택을 취소합니다.
- 최고 점수는 브라우저의 로컬 저장소에 보관합니다.

자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.
