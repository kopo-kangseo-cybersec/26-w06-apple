# 🍎 사과게임

상하좌우로 이어진 사과를 드래그해 합계 10을 만들고 점수를 얻는 짧은 퍼즐 게임입니다.

## 게임 소개

6×6 과수원에서 각 칸에 표시된 사과 개수(1~9)를 확인하고, 이웃한 칸들을 드래그해 합계가 정확히 10이 되도록 선택하세요. 수확에 성공하면 선택한 칸이 사라지고 칸마다 10점을 얻습니다. 합계가 10을 넘으면 현재 선택은 자동으로 취소됩니다.

제한 시간은 2분입니다. 현재 점수와 최고 점수가 표시되며, 최고 점수는 브라우저의 로컬 저장소에 보관됩니다. 효과음은 화면의 음표 버튼으로 켜고 끌 수 있습니다.

## 어떻게 만들었나요

Copilot Agent에 게임 규칙과 화면 요구사항을 프롬프트로 전달해 `index.html` 하나에 HTML, CSS, Vanilla JavaScript를 구현했습니다. 이후 선택 경로 하이라이트와 합계 초과 시 선택 취소를 추가하고, 격자를 6×6으로 조정한 뒤 숫자 대신 사과 이모지 개수로 값을 표현하도록 커스터마이징했습니다.

## 실행 방법

별도 설치나 빌드 과정은 필요하지 않습니다. 저장소에서 `index.html`을 브라우저로 열어 게임을 시작하세요.

## 커스터마이징한 부분

- 기본 예시의 8×8 숫자 격자를 6×6 사과 격자로 변경
- 각 칸의 숫자값을 같은 개수의 🍎 이모지로 표시
- 드래그 중 선택 칸 하이라이트와 합계 표시 제공
- 합계가 10을 초과하면 선택을 자동 취소
- 2분 타이머, 최고 점수 저장, 선택형 효과음 추가

실습 과정과 추가 커스터마이징 아이디어는 [guide.md](./guide.md)를 참고하세요.
